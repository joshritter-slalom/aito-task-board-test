# GenAI Standup Team Task Board

Temporary validation repository for the GenAI Standup Team Task Board.

## Contents

- `standup-living-board.html` — the self-contained, read-only board artifact.

The supporting workbook, vault notes, generated inspection files, and other local working files are intentionally excluded from this repository. Scheduled refreshes should publish a validated HTML artifact to the designated production target only after changes have been validated here.

## Environments

- **Test:** this repository, used for validation and peer review.
- **Production:** the future Slalom static-hosting repository/site provisioned by Slalom IT.

The production publishing workflow will be configured after the permanent hosting site and repository are available.
