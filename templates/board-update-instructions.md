# Board update instructions

This folder contains the instructions and working files used to keep the team task board current.

You can point your desktop agent at this shared folder and ask it to help you work through your updates privately. Tell it what changed in plain language. It should read these instructions and the workbook, find your open tasks, and make only the necessary update-row changes.

## Preferred ways to update

- Share the update in the approved meeting.
- Post it in the designated team chat. Use `board update <Card ID>` when convenient.
- Ask your desktop agent to update the shared workbook for you.
- Edit the workbook directly only when necessary.

Updates are processed on the team’s scheduled cadence. They are not expected to appear instantly on the HTML board.

## Safe behavior

- Read the relevant task row and history before editing.
- Prefer an existing task over creating a duplicate.
- Leave `Update ID` blank for a new update. Central processing assigns it from the workbook row.
- Work only on open rows in `Updates`.
- Do not rewrite the workbook, delete processed rows, or change unrelated tabs.
- Do not treat a missing task row as a request to remove it from the board.
- For removal, state `Remove from board`, include the Card ID, and provide a reason.
- If something is unclear or conflicts with existing information, flag it for administrator review.

## What makes an update useful

Describe what changed and the latest status. Include an owner, priority, and target date when known. A short update is fine; not every field needs to be completed every time.

## Administrator placeholders

Replace these values when creating an instance:

- Approved meeting names: `[team meeting names]`
- Approved chat: `[team chat link or connector identifier]`
- Update cutoff: `[local time and timezone]`
- Working folder: `[shared folder location]`
- Test board: `[test URL]`
- Production board: `[production URL]`
